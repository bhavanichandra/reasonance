# Reasonance
### Multi-Turn Reasoning That Resonates

Transform ambiguous mysteries into synthesized insights through iterative turn based hypothesis evolution



A Gemini-powered investigation engine where Sherlock Holmes conducts extended abductive inquiries across multiple turns, building hypothesis  graphs through explicit cross-referencing and thought continuity.



#### Tech Stack: 

- Spring Boot 4 
- Angular 
- Gemini 3 / Ollama (Gemma3n)
